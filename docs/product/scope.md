# Escopo Inicial — Sistema Lojasaph

## Objetivo desta definição

Separar o que precisa ser construído para substituir os controles atuais do que pode ser adicionado depois.

## MVP profissional

### Estrutura organizacional
- empresa;
- unidades;
- setores;
- locais de estoque.

### Cadastros
- produtos;
- categorias;
- fornecedores;
- funcionários básicos;
- usuários.

### Estoque
- entradas;
- retiradas;
- transferências;
- devoluções;
- perdas;
- ajustes;
- saldo;
- histórico;
- inventário físico.

### Validades
- lotes;
- datas de validade;
- alertas básicos.

### Financeiro
- notas fiscais;
- parcelas;
- contas a pagar;
- pagamentos;
- anexos e comprovantes.

### Caixa
- abertura;
- formas de pagamento;
- entradas;
- sangrias;
- taxas;
- fechamento;
- divergências.

### Administração
- autenticação;
- perfis e permissões;
- escopo por unidade;
- auditoria de operações críticas.

### Gestão
- dashboard operacional básico;
- relatórios essenciais;
- importação das planilhas atuais;
- exportação onde fizer sentido.

## Fase posterior

- pedidos de compra avançados;
- cotações;
- comparação de fornecedores;
- estoque mínimo;
- sugestão de compra;
- histórico avançado de custos;
- notificações externas;
- leitura de código de barras;
- PWA refinada;
- dashboards avançados.

## Futuro condicionado a necessidade real

- previsão de demanda;
- análise de sazonalidade;
- IA para consultas gerenciais;
- OCR de documentos;
- WhatsApp;
- integrações contábeis/fiscais;
- integrações com outros sistemas.

## Regra contra expansão descontrolada

Uma funcionalidade nova só entra no escopo quando houver processo real, usuário beneficiado e critério de aceite identificável.
